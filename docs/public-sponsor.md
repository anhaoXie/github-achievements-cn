# ❤️ Public Sponsor

## 触发条件

**通过 GitHub Sponsors 赞助开源项目或开发者**，一次性成就，无等级。

## 怎么拿

1. 打开 [github.com/sponsors](https://github.com/sponsors)，找一个你实际用过的开源项目或开发者。
2. 选择赞助档位（有 1 美元档的很多），绑定支付方式。
3. 完成赞助。

徽章会出现在你的个人资料里（赞助方也有对应的 sponsor 标记）。

## 关键细节

- **任意金额**：1 美元即可，不需要大额。
- **需要支付方式**：GitHub Sponsors 需要可用的国际支付方式（信用卡等），部分地区/银行卡可能不支持。
- **可以随时取消**：一次性赞助（one-time）也能触发，不必长期订阅。
- **这是唯一需要花钱的徽章**：量力而行，别为了徽章乱花钱。

## 现实建议

赞助你**每天在用**的项目：你 star 过的框架、用过其免费服务的工具、翻译/文档项目。哪怕 1 美元，也是对维护者的真实支持。这个徽章的意义本来就在于此。
