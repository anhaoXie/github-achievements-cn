# 🧠 Galaxy Brain

## 触发条件

**在 GitHub Discussions 中的回答被采纳为答案（accepted answer）**。

| 等级 | 门槛 |
| --- | --- |
| 基础 | 2 个 |
| Bronze（x2） | 8 个 |
| Silver（x3） | 16 个 |
| Gold（x4） | 32 个 |

## 怎么拿

1. 找一个开启了 Discussions 的仓库（很多开源项目都有 `Discussions` 标签页）。
2. 在别人的提问下写出**真正能解决问题的回答**。
3. 等提问者或维护者把你的回答标记为 **Accepted answer**。
4. 累计到门槛后解锁。

## 不踩坑

- **必须被采纳**：只是回答、点赞、被 ❤️ 都不算；要有 markdown 里那个「已采纳」标记。
- **仓库必须开启 Discussions**：你可以在自己仓库的 Discussions 里提问、回答，但自己采纳自己通常不算数的场景要避免（也不建议刷）。
- **不要刷问答**：GitHub 曾明确表示，为刷徽章而进行的「快速问答」属于协同造假，会被处理；社区官方仓库也因此关闭了成就统计。真实回答技术问题才是正道。
- **采纳方控制**：决定权在提问者/维护者，你能做的是把答案写清楚、附最小可复现示例、给出可验证链接。

## 现实建议

- 在自己熟悉的技术栈里订阅几个活跃仓库的 Discussions（如 Next.js、Prisma、各种框架），定期回答。
- 自己维护的项目里设置 FAQ，鼓励提问者采纳答案——但采纳要真实。
- 回答质量优先：一个被采纳的高质量答案，比十个「+1」有用。
