# ⭐ Starstruck

## 触发条件

**自己创建的仓库获得 star**（不是 fork 别人仓库获得的 star）。

| 等级 | 门槛 |
| --- | --- |
| 基础 | 16 ⭐ |
| Bronze（x2） | 128 ⭐ |
| Silver（x3） | 512 ⭐ |
| Gold（x4） | 4096 ⭐ |

## 怎么拿

没有捷径：**做一个别人真正想要的东西，然后让需要的人看到它**。

可行路径：

1. **做小工具**：解决一个具体痛点（格式转换、批处理、命令行小工具）。
2. **写中文指南 / 资料库**：把某个领域的零散知识整理成结构化的仓库（这是 star 增长最快的类型之一）。
3. **复现 + 踩坑记录**：复现论文、跑通某个环境、把踩坑写清楚，很多人会 star 收藏。
4. **提交到社区**：V2EX、掘金、少数派、Reddit、Hacker News、Awesome 列表——前提是内容真的有用。
5. **维护**：README 写清楚「解决什么问题、怎么用、截图/示例」，加 license，及时回 issue。

## 不踩坑

- **刷 star 会被清理**：买 star、互 star 群、小号 star 都属于虚假活动，GitHub 会移除 star 和成就。
- **fork 仓库的 star 不算**：Starstruck 只统计你创建的仓库。
- **不要写「求 star」式的空仓库**：既违反社区规范，也拿不到真实的 16 个。

## 现实建议

16 个 star 其实不难：一个解决真实小问题的仓库 + 发到两个合适的社区，通常一周内能到。难的是后面 128 / 512 的门槛——那需要持续维护和传播。
