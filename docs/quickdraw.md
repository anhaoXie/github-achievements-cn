# ⚡ Quickdraw

## 触发条件

**在打开 issue 或 PR 后的 5 分钟内把它关闭**，一次性成就，无等级。

## 怎么拿

1. 在公开仓库里新建一个 issue（或 PR）。
2. 在 5 分钟内关闭它。

自己开、自己关同样会触发——这本来就是「手快」彩蛋。

## 不踩坑

- **计时从创建时刻开始**：不是从你看到它开始，超过 5 分钟关闭就不触发。
- **issue 和 PR 都行**：两种都可以，但只算一次。
- **fork 里不算**：要在能正常计数的仓库里操作。
- **一次性**：拿到后再操作不会重复出现。

## 现实建议

最自然的场景：写 issue 时发现自己搞错了、重复提问、或描述有误，立刻关闭并说明原因。别为了刷徽章去别人的仓库里开垃圾 issue 再秒关——那是刷量。
