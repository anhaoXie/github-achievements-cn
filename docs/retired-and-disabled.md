## 小提示

成就系统的官方说明页已经被 GitHub 下线，网上流传的很多列表（包括一些「快速获得徽章」的帖子）把条件写错了，例如：

- ❌「YOLO = 锁定一个对话」——错，YOLO 是**未经 review 合并自己的 PR**。
- ❌「Quickdraw = 建仓库后 5 分钟内开 issue」——错，Quickdraw 是**打开 issue/PR 后 5 分钟内关闭**。
- ❌「Galaxy Brain = 随便回答一个问题」——错，必须**被采纳为答案**。

以 [社区维护清单](https://github.com/Schweinepriester/github-profile-achievements) 和 GitHub 实际行为为准。
