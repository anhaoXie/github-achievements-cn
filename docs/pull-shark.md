# 🦈 Pull Shark

## 触发条件

**你的 Pull Request 被合并**，累积达到门槛后解锁。

| 等级 | 门槛 |
| --- | --- |
| 基础 | 2 个已合并 PR |
| Bronze（x2） | 16 个 |
| Silver（x3） | 128 个 |
| Gold（x4） | 1024 个 |

## 怎么拿

1. 在自己的公开仓库（或参与别人的开源项目）里开一个分支，改点真东西。
2. 提交并推送分支。
3. 在 GitHub 上发起 Pull Request。
4. 合并 PR（合入默认分支）。

数量按**你作为作者的 PR** 累计，自己合并自己的 PR 也算。

## 不踩坑

- **合入默认分支才算**：合进 `main` / `master` 才算，合进普通分支不算。
- **fork 里开的 PR 不算**：必须合入上游仓库；在你 fork 出来的仓库里自己开 PR 不计数。
- **别刷**：连续大量无意义 PR 会被视为刷量，GitHub 可以移除成就，账号也可能受处理。
- **真实路径**：每天一个 commit 的挑战、把个人小项目拆成 PR 走一遍 review 流程、给用到的开源项目修 bug / 补文档。

## 适合刷数量的健康方式

- 给自己的项目做「PR 工作流」：每个功能一个分支一个 PR，合并后保留记录。
- 参与 Hacktoberfest 等开源活动，给真实项目提交小修复。
- 给文档仓库补翻译、修 typo——真实且低门槛。

> 提醒：这个徽章统计的是「合入的 PR 数」，不是提交数。一个 PR 里 100 个 commit 也只算 1 个。
