# 😅 YOLO

## 触发条件

**未经 code review 合并自己的 Pull Request**，一次性成就，无等级。

徽章弹窗里的文案：*You want it? You merge it.*（想要？自己合。）

## 怎么拿

1. 在自己的公开仓库里开一个分支，做一次真实改动（改文档也算）。
2. 发起 Pull Request。
3. **不要**请任何人 review，也不要给自己 approve。
4. 直接点击 Merge（或用 `gh pr merge`）。

Boom，YOLO 到手。

## 不踩坑

- **不能有 review 记录**：只要 PR 上有任何一条已提交的 review，这个 PR 就不触发。
- **必须是自己的 PR**：合并别人的 PR 不算。
- **一次性**：拿过之后再怎么合都不会重复出现。
- **合入默认分支**：和 Pull Shark 同样的要求。
- **fork 里不算**：操作要发生在正常仓库里。

## 现实建议

这个徽章本质是个彩蛋，鼓励「个人项目里别过度流程化」。日常最自然的拿法：个人项目里走一遍 PR 流程，自己合。

不要为了拿它去大项目的 PR 上强行绕过 review——那会影响真实协作，也可能违反仓库规则。
